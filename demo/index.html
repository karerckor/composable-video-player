Composable Video Player

1. Qualities, subtitles, thumbnails

[360p]…,[720p]… + subtitle (VTT + SRT) + sprite thumbnails. Settings menu, hotkeys, memory.

2. Audio tracks

{English}…;{Русский}… — separate files per language (440 Hz vs 660 Hz tone).

3. HLS

Adaptive stream via lazily loaded hls.js (native in Safari). Qualities come from the manifest, with “Авто”.

4. Playlist with folders

JSON playlist URL, panel open, autonext, prev/next buttons.

5. Extensibility: custom plugin, custom layout, theme

A plugin registers a skip10 component; the layout is a modified copy of defaultLayout; an action string api:seek,-10 drives a text button.

6. Fallback and errors

Left: missing.mp4 or video-360 (falls back). Right: a missing file (error overlay with retry).
